#### **Cafe Sales Data Cleaning using Excel**





**Project Overview**

Cleaned and standardised a 10,000-row dirty cafe sales dataset from Kaggle containing missing values, invalid entries and inconsistent formats.



**Dataset Source**

Kaggle: Cafe Sales – Dirty Data for Cleaning Training  

https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training



**Dataset Issues Identified**

\- Missing values

\- Invalid entries (ERROR, UNKNOWN)

\- Missing item and price information

\- Inconsistent date formats

\- Excel errors (#N/A, #VALUE!)

\- Missing categorical values



**Data Cleaning Performed**

\- Filled missing quantity values using median imputation

\- Corrected missing item values using XLOOKUP based on menu pricing

\- Replaced invalid values using IFERROR and logical conditions

\- Recalculated Total Spent values

\- Standardised transaction dates

\- Cleaned payment method and location fields

\- Produced an analysis-ready dataset



**Skills / Techniques Used**

\- Excel

\- Data Cleaning

\- XLOOKUP

\- IFERROR

\- Logical Functions (IF, OR)

\- Data Validation

\- Missing Value Treatment

\- Data Standardisation
